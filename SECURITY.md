# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue with exploit details, credentials, private logs, or personal data.

Include the affected endpoint or file, clear reproduction steps, expected impact, and any suggested mitigation. Reports are reviewed before public disclosure.

## Scope

The supported deployment is the current `main` branch and the public endpoint at https://lunoo.com/mcp.
